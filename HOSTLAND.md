# Развёртывание СИРИУС на Hostland

## 1. Создание Node.js-приложения

В панели Hostland откройте «Сайты» → «Прикрепление домена | Создание сайта», выберите
`сириус.net`, нажмите «Nodejs» и создайте приложение. Поле URL оставьте пустым, чтобы
приложение работало в корне домена. Стартовый файл — `server.js`.

## 2. Подготовка файлов

Локально выполните:

```bash
npm ci
npm run build
```

Загрузите в каталог Node.js-приложения:

- `server.js`;
- `package.json` и `package-lock.json`;
- всю папку `dist`;
- созданный по следующему шагу `config.local.js`.

Папки `src`, `public`, `api` и `node_modules` для рабочего сервера не нужны.

## 3. Telegram-настройки

Скопируйте `config.local.example.js` в `config.local.js` и укажите настоящий токен бота и
ID чата. Не кладите `config.local.js` в Git и не помещайте его внутрь `dist`.

Если панель Hostland позволяет задать переменные окружения, вместо файла можно указать
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` — сервер поддерживает оба способа.

## 4. Перезапуск

После загрузки файлов измените или создайте файл:

```text
/home/hostXXXXXXX/domain_name/projects/app_catalog/tmp/restart.txt
```

Точный путь показывается в панели Hostland. Логи Node.js/Passenger находятся в
`/home/hostXXXXXXX/passenger_log` при включённом ведении логов.

## 5. Проверка

Откройте `https://сириус.net/booking` и отправьте одну тестовую заявку. API должен отвечать
по адресу `https://сириус.net/api/telegram`. Запрос `GET` к этому адресу штатно возвращает
ошибку 405 — обработчик принимает только `POST`.
